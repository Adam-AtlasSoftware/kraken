KRAKEN release archive
======================

Contents
  bin/                       kraken (CLI and MCP server), krakend (daemon), kraken-gui, and on
                             Linux kraken-native-worker (the native engine's decompiler
                             process) and kraken-emu-run (the emulator's sandbox)
  share/kraken/native-sla/   (Linux) Ghidra's processor specifications compiled for the native
                             engine, so it needs no Java, no Ghidra and no setup
  share/kraken/kraken-ghidra.jar
                             prebuilt Ghidra extension; `kraken setup` installs it, so you do
                             not need Gradle or a JDK to build it
  share/kraken/kraken-dotnet/
                             prebuilt .NET sidecar; `kraken setup --dotnet` installs it next to
                             a pinned .NET runtime
  share/applications, share/icons
                             (Linux) the app's desktop entry and icon
  docs/                      the documentation (open docs/index.html)
  README.md, LICENSE, THIRD-PARTY-NOTICES.md
  licenses/                  license and notice files of the Ghidra decompiler (Apache-2.0)
                             and zlib, which the native engine compiles into the programs

Install
  1. Put the three programs on your PATH, keeping share/kraken next to bin/:
       Linux/macOS:  cp -R bin share ~/.local/        (and make sure ~/.local/bin is on PATH)
     or run scripts/install.sh from the repository, which does this after checking the download.
       Windows:      unzip anywhere and add its bin folder to PATH
     KRAKEN finds kraken-ghidra.jar next to the program or in ../share/kraken.
  2. Linux: the native engine works right away (`kraken setup --native` checks it). For the
     optional Ghidra engine (Mach-O, other processors, PDB) and on macOS and Windows, run
     `kraken setup`: it downloads the pinned Ghidra and Temurin JDK 21 (both checked against
     compiled-in SHA-256 hashes) into your user data directory. Nothing needs root.
  3. Optional, for .NET assemblies (C# decompilation): `kraken setup --dotnet`. It downloads the
     pinned .NET runtime (SHA-256 checked before it is unpacked) and installs the sidecar from
     share/kraken. Without it, .NET files are refused with a message pointing here.
  4. Try it: `kraken --help`, or start `kraken-gui`.

Verify the download
  Compare the archive with SHA256SUMS from the release page:
       sha256sum -c SHA256SUMS --ignore-missing
  Release archives also carry GitHub build provenance attestations:
       gh attestation verify <archive> --repo Adam-AtlasSoftware/kraken

macOS
  The binaries are ad-hoc signed, not notarized yet. If Gatekeeper blocks a program, run
       xattr -d com.apple.quarantine bin/*
  or allow it in System Settings -> Privacy & Security.

Windows
  The programs are not signed yet. SmartScreen may warn; choose "More info" -> "Run anyway".

Uninstall
  Remove the programs you copied, and the data directory (~/.local/share/kraken on Linux,
  holding the downloaded Ghidra and JDK) and ~/.config/kraken.
